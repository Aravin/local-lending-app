# Design System — Kinship Lending System

Based on the mobile-first design spec from Stitch (Project `5305874959380477439`).

## Visual Aesthetic

- **Concept**: Modern Corporate Fintech with a Human Touch.
- **Form Factor**: Mobile First (390px base width, scalable).
- **Core Font**: Inter (Google Fonts) with weights 400, 500, 600, 700.

## Color Palette (Default Flavor: Local Lending Hub)

| Token | Hex | Role |
|---|---|---|
| Primary | `#0D9488` | Main action buttons, active navigation, brand headers |
| Secondary | `#006E2F` | Positive ROI, approval chips, repayment success |
| Tertiary | `#3452C1` | Trust badges, security badges, secure locks |
| Surface | `#F8F9FF` | App background, soft cards |
| On Surface | `#0B1C30` | High-contrast body text and titles |
| Surface Container | `#E5EEFF` | Secondary card fills, chip backgrounds |
| Error | `#BA1A1A` | Overdue notices, validation errors, reject actions |
| Outline | `#6D7A77` | Unfocused text field borders, dividers |

## Corner Radii

- Small elements (text fields, badges): `8px` (`0.5rem`)
- Cards & bottom sheets: `16px` (`1rem`)
- Primary CTA buttons: `24px` (`1.5rem`) — tactile touchable shape
- Status chips: `9999px` (full pill shape)

## Typography Scale

- **Display Large**: 32px / 700 / -0.02em tracking
- **Headline Large**: 24px / 600 / -0.01em tracking
- **Headline Medium**: 20px / 600
- **Title Large**: 18px / 600 (App bars)
- **Body Large**: 16px / 400
- **Body Medium**: 14px / 400
- **Label Large / Buttons**: 14px / 600
- **Label Medium**: 12px / 500
